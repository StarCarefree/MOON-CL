# 我的游戏组件工作台

原生 WPF 页面，沿用 MOONCL 深灰 / 琥珀金主题，不覆盖右侧原有账号和启动操作。

- 页面右上角「添加组件」打开可搜索的组件目录；添加后进入草稿编辑模式。
- 「编辑布局」中可拖动标题排序，也可用上下移按钮。组件设置支持自定义标题与「占满一行」。
- 可选择单列 / 双列；内容宽度小于 620 DIP 时自动单列，不改变保存的偏好。
- 便签可编辑多行内容；版本快捷入口可绑定当前游戏文件夹内的已安装版本。便签和快捷入口可重复添加。
- 「保存布局」才写入页面 `DashboardPath` 指定的布局文件；取消恢复本轮编辑前的状态，恢复默认也需保存才生效。
- 共13类组件：当前游戏、今日问候、最近游玩、我的游戏库、日历、游玩统计、版本快捷入口、便签、收藏游戏、单人世界、已保存服务器、常用操作、游戏文件夹。
- 现有自定义主页内容、社区提示、调试日志及运行中实例卡片继续保留。最近游玩仍依据 `logs/latest.log` 修改时间，共享目录的版本合并显示，不代表精确启动历史。

## 验证

先将主项目编译到独立目录（不替换正在运行的启动器）：

```bash
dotnet build 'Plain Craft Launcher 2/Plain Craft Launcher 2.csproj' -c Debug -p:Platform=x64 -p:OutputPath='D:/pcl-cy/PCL-CY/artifacts/dashboard-build/' --no-restore
dotnet test PCL.Core.Test/PCL.Core.Test.csproj -c Debug -p:Platform=x64 --no-restore --filter 'FullyQualifiedName~GameDashboard|FullyQualifiedName~GamePlayHistory'
dotnet run --project scripts/dashboard-ui-smoke/Dashboard.UiSmoke.csproj -- 'D:/pcl-cy/PCL-CY/artifacts/dashboard-build' "$PI_SCRATCH_DIR"
```

可用 `-p:LauncherOutput=...` 指定其他主项目构建目录，并把同一路径传给测试程序第一个参数。需要 .NET 10 SDK 与 Windows WPF 运行时；本机实际验证使用 `I:/dev/dotnet/dotnet.exe`，运行时环境 `DOTNET_ROOT` / `DOTNET_ROOT_X64` 同指向 `I:/dev/dotnet`。

UI 冒烟测试使用独立、随机命名的临时配置目录，不启动完整启动器生命周期，不登录、不下载、不启动游戏。除原有布局交互外，`InsightsChecks.cs` 还验证翻月跨年、回到今天、日期便签写入、时间范围与版本筛选、趋势图与日历联动、重建后保留筛选、新组件空状态和编辑模式禁用内容动作。本轮工作区运行55项原生检查全部通过；图表样例由测试给独立页面注入，不写入实际历史。核心相关测试共38项通过，包含原有布局测试、报表/CSV/便签、世界与服务器只读预览、真实历史计时与时间边界。

未执行真人鼠标拖放与真实 Minecraft 启动测试；排序逻辑、替代按钮、真实弹窗和原生布局已在独立控件实例中验证。截图不包含完整启动器外壳。

## 日历、统计与实用组件

- 日历支持前后月份、回到今天、点击日期、按版本筛选、时长热力、每日版本明细与日期便签。便签保存到 `Paths.SharedData/game-calendar-notes.json`，与组件布局独立；留空保存可删除，删除组件不删除便签。读取损坏文件时禁用写入，避免覆盖原数据。
- 统计支持今日、近7天、近30天、本月、全部每日记录和版本筛选；展示时长、会话数、活跃日、活跃日均、最长连续天数、版本前5名与最近30天趋势。点击柱条联动日历，没有日历时弹出当天记录。CSV 导出与当前筛选一致，UTF-8 BOM 编码，并转义逗号/换行/引号和表格公式前缀。
- `Paths.SharedData/game-play-history.json` 保存最近三年的真实每日记录。从更新后被启动器观察到的运行会话开始积累，不把旧版累计时长伪造为每日数据；旧版累计另列。只跟踪本启动器观察到的游戏，启动器不运行时无法补录。
- 同路径多进程按一个版本的连续运行计时；不同版本同时运行分别累计，所以总“版本时长”可能大于墙钟时间。跨本地午夜拆分时长，会话次数只归开始日；按分钟节流保存，启动/停止及退出提交时尝试立即保存，异常退出最多可能丢失未提交片段。保存失败保留内存并提示，后续重试。计时保留不足一秒的余量，避免高频 Tick 少算。
- 收藏游戏读取现有版本收藏状态；常用操作复用原生安装、版本、任务、联机、好友和设置导航。文件夹入口跟随当前版本，只打开已存在目录，不创建目录。
- 单人世界与已保存服务器读取当前所选版本的 `PathIndie`，后台扫描并缓存30秒，可手动刷新。切换版本后旧请求不会回写，新数据未就绪时不显示上个版本的列表。世界仅预览最多100个近期目录中的6个最近存档；服务器最多预览6项、隐藏项不显示。点击世界打开文件夹，点击服务器复制地址；不修改游戏文件、不自动进服。
- 原生截图来自独立页面，并不证明实际 Minecraft 启动或真人鼠标拖放。最新预览在工作区 `artifacts/dashboard-expanded-preview/`（忽略的构建产物）。
