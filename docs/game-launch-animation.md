# MOONCL 游戏启动动画

点击“启动游戏”后，在原生主页内容区显示炭黑/暖金的月轨加载页。原标题栏、侧栏和右侧启动面板保留；没有新增 WebView2，也不向游戏目录安装加载模组。

## 启用与关闭

设置 → 个性化 → 基础选项 → **启用游戏启动动画（MOONCL）**。

默认开启，配置键为本地 `UiShowLaunchAnimation`，切换后下次启动游戏生效。关闭时仍使用原有进度面板，不影响游戏启动。导出启动脚本不显示动画页。

## 行为

- 月牙、轨道光点和山景与 MOONCL 炭黑/暖金风格一致；尊重 Windows 客户区动画开关。
- 版本名、阶段、进度和补全下载速度来自现有启动任务；计时为实际经过时间，不虚构模组加载量，也不设置最短动画时长。
- “返回主页”只收起加载页，启动继续；“取消启动”复用原取消处理。
- 完成、失败、取消及返回登录区都会收起页面；不可见或卸载时停止计时器和动画。
- 保留已有多实例启动策略：只在首个启动会话进入进度面板时展开，不强行覆盖第二次启动时的主页。

参考说明：请求中提供的 `exmo/mod-loading-screen` 未在工作区找到，同名 GitHub 地址查询返回 404，因此本实现为 MOONCL 原生重新设计，不声称复用了其源码或实现了游戏内部的模组加载遥测。
